About This Tool

This is a rule-based phishing URL checker that analyzes URL structure for common phishing indicators. It checks for suspicious patterns like IP addresses, unusual TLDs, excessive subdomains, and more.

Note: This tool uses heuristic analysis only and may have false positives/negatives. Always use caution with suspicious links.
